The GS orbitals in the orbital gallery do not look like plane waves. *Inference:* for a Γ-only, cubic-periodic, uniform-jellium LDA system the eigenstates of Ĥ_KS are pure plane waves only when every degenerate shell is *fully* occupied (Σ_{G∈shell}|ψ_G|² ≡ #shell/V regardless of unitary mixing inside the shell). When a shell is *partially* filled, the SCF returns an arbitrary orthonormal basis spanning the partial subspace, and the resulting density is generically non-uniform. The gallery panels are 2D xy-mid-plane slices of |ψ_i(r)|² (per `inq-stack/python/inqview/postprocess/ground_state.py`), so the answer to "are these density slices in xy?" is **yes**.

![GS orbital gallery (xy mid-plane density slices)](attachments/2026-05-03_run_base/gs_orbital_gallery.png)

The GS density xy slice shows ≈ 20 % spatial variation around the nominal r_s = 7.38 jellium density (5.4e-4 .. 6.5e-4 bohr⁻³, mean 5.94e-4). *Inference:* this is the partial-shell artefact above. N = 128 falls between the closed-shell magic numbers **114** and **138** (cumulative count of paired (n_x,n_y,n_z) integer triples with n_x²+n_y²+n_z² ≤ k) and partially fills the |G|² = 6 shell, which is exactly what the broken-symmetry density and the localised orbital blobs imply. `Source: docs/sources/free-electron-gas-magic-numbers.md (verified by Python enumeration, 2026-05-03); Ashcroft & Mermin Ch. 2.`

![GS density xy mid-plane (≈ 20 % spatial variation)](attachments/2026-05-03_run_base/density_gs_system_xy.png)

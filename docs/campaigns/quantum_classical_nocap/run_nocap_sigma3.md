<description>
Run the EXACT same quantum-vs-classical configuration as the WITH-CAP study
("Study A", `docs/plans/quantum-classical-sigma3-stopping.md`), but with the complex
absorbing potential REMOVED. The CAP is the only substantive difference, so this no-CAP
twin (a) isolates exactly what the absorber does (A − B), and (b) gives a clean periodic
single-pass stopping with no absorber artefacts. The projectile now crosses the periodic
box and wraps instead of being absorbed, so it is relaunched closer to the boundary for a
longer clean traversal. Measure the SAME observables and do the SAME analysis as Study A.
PROVISIONAL until the inq-study engine regression (Task #7).
</identity>

- Energy: 300 eV (k0 = v0 = 4.696 a.u.).

  Sanity: electron_number stays flat (no drainage), unlike Study A.
</config>

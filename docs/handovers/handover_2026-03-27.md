## INQ API Quick-Reference (most common mistakes)

- Smearing for metals: `.temperature(0.086_eV)` NOT `.smearing()`
- Impulsive ionic dynamics: `.impulsive()` in `options::real_time{}`, NOT a template parameter
- Current observable: `.observables_current()` in `options::real_time{}`
- k-grid: `input::kpoints::grid({nx, ny, nz}, true)` (second arg = shifted)
- Save/load: `electrons.save("dir")` / `electrons.load(ions, "dir")`
- GPU confirmation in log: `"process 0 has gpu id <hash>"`

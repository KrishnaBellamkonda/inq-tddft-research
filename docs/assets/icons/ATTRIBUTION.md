# Icon libraries — provenance & licenses

Downloaded via jsDelivr CDN (flat SVGs), targeted subset only (no full clone).

## material/  — Google Material Symbols (outlined, weight 400)
- Source: `@material-symbols/svg-400` (npm) = Google Material Symbols.
- Upstream: https://github.com/google/material-design-icons
- License: **Apache License 2.0** (free for commercial/academic use, no
  attribution required but appreciated).

## scientific/  — Font Awesome Free (solid)
- Source: `@fortawesome/fontawesome-free` (npm), `svgs/solid/`.
- Upstream: https://github.com/FortAwesome/Font-Awesome
- License: **icons = CC BY 4.0** (attribution REQUIRED when used in a
  published figure), fonts = SIL OFL 1.1, code = MIT.
- Attribution string for captions/acknowledgements:
  "Icons: Font Awesome Free (CC BY 4.0, fontawesome.com)."

Add new icons by fetching individual SVGs from the same CDN paths; do not clone
the full repos (hundreds of MB; disk is near full).
